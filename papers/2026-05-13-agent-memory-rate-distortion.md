# Remember the Decision, Not the Description: A Rate-Distortion Framework for Agent Memory

- **arXiv ID**: 2605.10870
- **カテゴリ**: cs.AI (AI全般)
- **投稿日**: 2026-05-11
- **URL**: https://arxiv.org/abs/2605.10870

## 著者
Mingxi Zou, Zhihan Guo, Langzhang Liang, Zhuo Wang et al.

## 選定理由
✅ **理論的新規性**: エージェントメモリに情報理論のレート歪み理論を適用した先駆的研究
✅ **実用重要性**: 長期ホライゾンエージェントの実用化を阻むメモリ問題への根本的アプローチ

## 概要
長期ホライゾンエージェントは限られたランタイムメモリで動作しなければならないが、既存のメモリ機構は「関連性・顕著性・要約品質」などの記述的基準でメモリを整理している。しかしエージェントにとって記憶が有価値なのは過去を忠実に描写するからではなく、固定された予算の下で「分離すべき履歴の区別」を保存するからだ。レート歪み理論でこれを形式化。

## 主要な貢献
1. **意思決定指向メモリ**: 「記述」ではなく「意思決定」を保存する原則の形式化
2. **レート歪みフレームワーク**: 情報理論でエージェントメモリの最適圧縮を定式化
3. **実践的アルゴリズム**: 理論に基づいた効率的メモリ管理の実装
4. **実証的検証**: 長期ホライゾンタスクでの性能改善

## 実験結果
- 記述的メモリより意思決定指向メモリの方がタスク成功率が高い
- メモリ予算を削減してもタスク性能を維持

## インパクト
「何を覚えるべきか」というエージェントメモリの根本問題に情報理論の枠組みで答えを出す重要研究。
