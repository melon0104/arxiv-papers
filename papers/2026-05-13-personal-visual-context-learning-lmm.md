# Personal Visual Context Learning in Large Multimodal Models

- **arXiv ID**: 2605.10936
- **カテゴリ**: cs.CV (コンピュータビジョン)
- **投稿日**: 2026-05-11
- **URL**: https://arxiv.org/abs/2605.10936

## 著者
Zihui Xue, Ami Baid, Sangho Kim, Mi Luo et al.

## 選定理由
✅ **ウェアラブル×AI**: スマートグラス等のウェアラブルデバイスとLMMの統合という最先端テーマ
✅ **実用性**: パーソナルAIアシスタントの視覚パーソナライゼーション研究

## 概要
スマートグラス等のウェアラブルデバイスがLMMをユーザーの継続的な一人称視覚ストリームに統合するにつれ、「その人固有の視覚情報を推論する」能力（視覚パーソナライゼーション）が重要になる。Personal VCL（Personal Visual Context Learning）という新タスクを形式化：プロンプト時にユーザー固有の視覚コンテキストを用いて個人化クエリを解決する能力。

## 主要な貢献
1. **Personal VCL**: 新しいタスク定義と評価フレームワークの確立
2. **ベンチマーク構築**: スマートグラスを想定した個人化視覚QAデータセット
3. **評価**: 現行LMMの個人化能力の体系的評価
4. **技術的洞察**: プロンプト時の視覚コンテキスト活用の限界と可能性

## 実験結果
- 既存LMMは個人化視覚コンテキストの活用に弱点があることを実証
- 専用訓練で大幅な改善が可能

## インパクト
MetaのRay-Ban Smart Glassesや将来のARデバイスに搭載されるLMMのパーソナライゼーション研究として重要。
