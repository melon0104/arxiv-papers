# Shepherd: A Runtime Substrate Empowering Meta-Agents with a Formalized Execution Trace

- **arXiv ID**: 2605.10913
- **カテゴリ**: cs.AI (AI全般)
- **投稿日**: 2026-05-11
- **URL**: https://arxiv.org/abs/2605.10913

## 著者
Simon Yu, Derek Chong, Ananjan Nandi, Dilara Soylu (Meta AI)

## 選定理由
✅ **有名機関**: Meta AI
✅ **実用性**: メタエージェントシステムの実用的ランタイム基盤—Dockerより5倍高速なfork

## 概要
Shepherdはメタエージェント（別エージェントを制御するエージェント）の動作を関数として形式化する関数型プログラミングモデル。すべてのエージェント-環境インタラクションをGit風の型付き実行トレースとして記録し、任意の過去状態からforkして再実行可能。Dockerより5倍高速なエージェントプロセスforkと95%超のプロンプトキャッシュ再利用を実現。

## 主要な貢献
1. **形式的実行トレース**: Lean 4で機械的に検証された核操作
2. **高速Fork**: Dockerより5倍高速なエージェントプロセスfork
3. **プロンプトキャッシュ再利用**: リプレイ時に95%超のキャッシュヒット率
4. **3つのアプリケーション**: エージェント実行の検証・デバッグ・最適化を実証

## 実験結果
- fork速度: Docker比5倍高速
- キャッシュ再利用率: 95%超（コスト削減）
- SWE-bench等での有効性を実証

## インパクト
AIエージェントのデバッグ・監査・最適化の実践的基盤を提供。エージェントシステムの信頼性と効率を同時に高める。
