# LongMemEval-V2: Evaluating Long-Term Agent Memory Toward Experienced Colleagues

## 概要

専門ウェブ環境でのエージェントの長期記憶評価に特化したベンチマーク。成功は、インターフェースのアフォーダンス・状態遷移・ワークフロー・繰り返す失敗パターンの想起にかかっているが、既存のメモリベンチマークはユーザー履歴・短いトレース・下流タスク成功にのみ焦点を当てており、エージェントがメモリシステムを通じて環境固有の経験を内在化しているかの直接評価が欠落していた。

LongMemEval-V2（LME-V2）は「経験豊富な同僚」のような振る舞いを目指すエージェントを評価するためのベンチマーク。

## 選定理由

- エージェントメモリという急成長トレンド
- ウェブエージェントの実用的評価に特化
- LongMemEval系の後継として信頼性高い

## キーポイント

- **課題**: 既存メモリ評価は浅く、環境固有知識の内在化を測れない
- **手法**: 専門ウェブ環境でのエージェント長期記憶の直接評価フレームワーク
- **目標**: 「経験豊富な同僚」レベルのエージェントを定義・評価
