# PRISM: Pareto-Efficient Retrieval over Intent-Aware Structured Memory for Long-Horizon Agents

## 概要

長期エージェントのメモリ管理問題に取り組む論文。会話履歴がコンテキストウィンドウを超える速さで蓄積される中、既存手法はコンテキスト拡張・重いファクト抽出・ヒューリスティックなグラフ探索のいずれかに頼っており、それぞれ精度・コスト・トレードオフで課題を抱える。

PRISMはPareto効率的な検索フレームワークで、Intent-Aware Structured Memoryを構築し、精度とコストのトレードオフを最適化する。

## 選定理由

- cs.CLのトップ論文に分類
- 長期エージェントメモリという重要トピック
- 情報検索・推薦との関連性が高い

## キーポイント

- **課題**: 長期ホライゾンエージェントのメモリ蓄積がコンテキストウィンドウを超える問題
- **手法**: Pareto効率的な検索でIntent-Aware構造化メモリを活用
- **意義**: 精度とトークンコストの両方を最適化する新しいアプローチ
