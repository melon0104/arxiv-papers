# Coverage, Not Averages: Semantic Stratification for Trustworthy Retrieval Evaluation

## 概要

RAGの精度・頑健性の主要ボトルネックは検索品質。現行評価は**ヒューリスティック構築のクエリセット**に依存し、隠れた内在バイアスを持つ。本論文は検索評価を**統計的推定問題**として定式化し、corpus構造に基づく「セマンティック層別化（semantic stratification）」でクエリセット構築のバイアスを解消する。

## 選定理由

- RAG評価の根本的問題を統計理論から解決
- 実務でのRAG品質評価に直接利用可能

## 手法

- **セマンティック層別化**: コーパスを意味的クラスタに分割し、各クラスタから均一にクエリをサンプリング
- 検索評価の信頼性を統計的に保証するフレームワーク
- 平均指標ではなくカバレッジ（全意味領域の網羅性）で評価

## 主要な知見

- 従来のheuristic query setは特定のトピック・難易度に偏る
- 層別化によりメトリックの推定誤差を大幅削減
- 平均スコアより「意味的カバレッジ」が信頼性の真の指標

## 意義

RAGシステムを本番展開する際の評価設計に直接活用できる実用的フレームワーク。バイアスのある評価セットによる誤った意思決定を防ぐ。
