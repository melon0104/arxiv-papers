# Tool Attention Is All You Need: Dynamic Tool Gating and Lazy Schema Loading for Eliminating the MCP Tax

## 概要

Model Context Protocol（MCP）を使ったLLMエージェントが、全ツールスキーマを毎ターン静的に注入する「MCPタクス（MCP Tax）」によって10K〜60Kトークンを無駄消費する問題を指摘。**動的ツールゲーティング**と**遅延スキーマロード**で、必要なツールのスキーマのみを動的に注入する効率化手法を提案。

## 選定理由

- MCP（急速普及中の標準プロトコル）の実運用課題に直接対応
- エージェント型AIの実用コスト削減に直結
- コンテキストウィンドウ効率化という産業上重要な問題

## 手法

- **動的ツールゲーティング**: クエリに応じて必要なツールのみを選択的に有効化
- **遅延スキーマロード（Lazy Schema Loading）**: 実際に使用が予測されるツールのスキーマのみを注入
- アテンション機構を活用したツール関連性の推定

## 主要な知見

- 典型的マルチサーバー構成での「MCPタクス」は10K〜60Kトークン/ターン
- 動的ゲーティングでコンテキスト消費を大幅削減
- ツール選択精度を維持しながらKVキャッシュ使用量・コスト・レイテンシを削減

## 意義

LLMエージェントのMCP活用が普及する中、スケーラビリティの実際的ボトルネックを解決する実践的貢献。トークンコストを気にする全エージェント開発者に関連。
