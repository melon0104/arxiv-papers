# Context Unrolling in Omni Models

## 概要

テキスト・画像・動画・3D・隠れ表現など多様なモダリティをネイティブ学習した統合マルチモーダルモデル「Omni」を提案。学習中に**Context Unrolling**（文脈展開）という現象を発見：モデルが複数モーダル表現を横断して明示的に推論してから予測を生成することで、ヘテロな情報を統合した高精度な推論が実現する。

## 選定理由

- マルチモーダル統合モデルの新現象「Context Unrolling」を発見・命名
- テキスト・画像・動画・3D統合という包括的なOmniモデル

## 手法

- 5種類のモダリティ（テキスト、画像、動画、3D幾何、隠れ表現）を統一学習
- Context Unrolling: 予測前に複数モーダル表現を明示的に展開・集約
- 共有マルチモーダル知識多様体への近似精度を向上

## 主要な知見

- Context Unrollingによりモーダル間の補完的情報を効果的に統合
- 単一モーダルより複数モーダル入力で一貫した性能向上
- 3D理解を含む多様なベンチマークで強力な結果

## 意義

「複数モーダルで考える」能力を持つ真のOmniモデルへの道標。隠れ表現をモダリティとして扱うアイデアは今後のマルチモーダル研究に影響を与えると予想。
