# Data-Free Contribution Estimation in Federated Learning using Gradient von Neumann Entropy

**arXiv:** https://arxiv.org/abs/2604.22562  
**公開日:** 2026-04-24  
**カテゴリ:** cs.LG / cs.CV

## 著者
Asim Ukaye, Mubarak Abdu-Aguye, **Nurbek Tastan**, **Karthik Nandakumar** (MBZUAI)

## 概要
連合学習でのクライアント貢献度推定は、サーバー側検証データや自己申告情報に頼るためプライバシー問題やmanipulationリスクがある。本研究は**勾配のvon Neumann Entropy**を信号として使うデータフリーな貢献度推定手法を提案。外部データなしにクライアントの重要性を公平・プライバシー保護で評価。

## ポイント
- サーバー検証データ不要のデータフリー手法
- 行列von Neumann Entropyを貢献度プロキシとして使用
- プライバシー保護と公平な報酬分配を両立
- 操作耐性（manipulation-resistant）な設計

## 関連性
プライバシー保護ML・連合学習のインセンティブ設計に重要な貢献。
