# Can QPP Choose the Right Query Variant? Evaluating Query Variant Selection for RAG Pipelines

**arXiv:** https://arxiv.org/abs/2604.22661  
**公開日:** 2026-04-24  
**カテゴリ:** cs.IR

## 著者
Negar Arabzadeh, Andrew Drozdov, **Michael Bendersky** (Google), Matei Zaharia

## 概要
LLMが多様なクエリ変形（reformulation）を生成する現代RAGパイプラインでは、すべてのバリアントを実行するのはコスト過多。**QPP（Query Performance Prediction）**をクエリバリアント選択機構として活用できるかを検証。どのクエリが最良かを事前推定することで、下流処理コストを削減する。

## ポイント
- Google著者含む実用指向の研究
- QPPをRAGのクエリ選択フィルタとして評価
- 計算コスト削減と品質トレードオフを詳細分析
- 複数クエリ変形戦略に対するQPPの有効性を実証

## 関連性
RAGシステムの実装効率化に直結。クエリ拡張を使っているシステムへの即時適用価値が高い。
