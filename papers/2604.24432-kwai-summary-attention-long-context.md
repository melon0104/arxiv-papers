# Kwai Summary Attention Technical Report

## 概要

快手（Kuaishou）の研究チームによるLong-context推薦システム向け高効率Attentionメカニズムの技術レポート。標準的なSoftmax Attentionの二乗計算量問題を解決し、超長系列ユーザー履歴を使った推薦モデルのスケーラビリティを実現。

## 問題設定

- LLMベースの推薦システムでは系列長が長くなるほど、標準Softmax Attentionの計算コスト（O(n²)）が爆発的に増大
- 快手の本番推薦システムは数千〜数万のユーザー行動履歴を扱う必要がある
- メモリ・推論コストが実用化のボトルネックになっていた

## 提案手法：Summary Attention

- **サマリートークン**：長い履歴シーケンスを圧縮した固定長のサマリー表現を生成
- **階層的Attention**：サマリートークンを介した2段階のアテンション計算でO(n)〜O(n log n)に削減
- **コンテンツ保持**：重要な行動パターンを損失なくサマリーに凝縮する学習機構
- 推薦タスク特有の**item-user相互作用**に最適化された設計

## 実験結果

- 快手の本番システム（**production deployment**）で検証
- 標準Attentionと同等の推薦精度を維持しつつ、計算コストを大幅削減
- 超長系列（10K+トークン）でのスケーラブルな学習・推論が可能

## 意義

Kuaishouの**実運用環境（production）で実証済み**の技術報告。LLM×推薦システムの産業応用における計算効率問題への実践的解答。長文脈推薦システムの設計に直接役立つエンジニアリング知見。
