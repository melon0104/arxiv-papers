# DepthKV: Layer-Dependent KV Cache Pruning for Long-Context LLM Inference

**Authors:** Zahra Dehghanighobadi, Asja Fischer

**arXiv:** https://arxiv.org/abs/2604.24647  
**Published:** 2026-04-27

## 概要

長文脈LLM推論においてKVキャッシュのメモリフットプリントはシーケンス長に線形で増加し、深刻なボトルネックになる。既存のKVキャッシュ刈り込み手法はアテンションスコアが低いトークンを削除するが、ほとんどが全レイヤーに同一の戦略を適用している。

## 提案手法

**DepthKV**：レイヤーごとに異なるKVキャッシュ刈り込み戦略を適用。

- 浅いレイヤーと深いレイヤーでアテンションパターンが異なることを活用
- レイヤー深度に依存した適応的な刈り込み率を設定
- ロングコンテキスト理解・要約・コード生成タスクで有効性を検証

## 重要性

LLMの長文脈処理効率化は推論コスト削減の要。レイヤー依存の設計思想は今後の推論最適化研究のベースラインになりうる。
