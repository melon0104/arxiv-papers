# Agent-Centric Visual Reinforcement Learning under Dynamic Perturbations

**Authors:** Zhengru Fang, Yu Guo, Fei Liu

**arXiv:** https://arxiv.org/abs/2604.24661  
**Published:** 2026-04-27

## 概要

視覚的強化学習は視覚的観測からポリシーを学習するが、動的な視覚的摂動（腐食タイプの予測できない変化など）に対して脆弱。

## 提案手法

**Visual Degraded Control Suite (VDCS)**：DeepMind Control Suiteを拡張したベンチマーク。
- マルコフスイッチング劣化により非定常な実世界の摂動をシミュレート
- エージェント中心の視点から視覚的堅牢性を評価
- 既存手法が動的摂動下で深刻な性能劣化を示すことを実証

## 重要性

DeepMindコントロールスイートとの関連で多くの研究者が追試しやすいベンチマーク。実世界ロボット展開における視覚的堅牢性の重要性を改めて示す研究。
