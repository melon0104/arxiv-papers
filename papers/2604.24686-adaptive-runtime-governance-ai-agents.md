# Governing What You Cannot Observe: Adaptive Runtime Governance for Autonomous AI Agents

**Authors:** German Marin, Jatin Chaudhary

**arXiv:** https://arxiv.org/abs/2604.24686  
**Published:** 2026-04-27

## 概要

自律AIエージェントは完全に承認されたまま安全でなくなりうる。コード変更なしでも行動ドリフト・敵対的適応・意思決定パターン変化が起きる。

## 提案手法

**Informational Viability Principle（情報的実行可能性原則）**：
- 観測されていないリスクの上限を推定するフレームワーク
- `B̂(x) = U(x) + SB(x) + RG(x)` で非観測リスクをモデル化
- アクションの容量 `S(x)` が上限を安全マージン分上回る場合のみ許可
- **Agent Viability Framework**: Aubinの実行可能性理論を基盤

## 重要性

本番デプロイされたAIエージェントのリアルタイムガバナンス問題を扱う。エージェント自律性が増すにつれ重要性が増す監視フレームワーク。OpenClawのようなシステムへの実装示唆がある。
