# Refinement via Regeneration: Enlarging Modification Space Boosts Image Refinement in Unified Multimodal Models

## 概要

視覚理解と生成を統合したUnified Multimodal Models（UMM）における画像精緻化を改善する「Refinement via Regeneration（RvR）」パラダイムを提案。現行の「editing-based refinement」の限界を克服し、より大きな修正空間を確保することで高品質な画像生成を実現。

## 問題設定

- UMMはtext-to-image（T2I）タスクで初期生成後に出力を精緻化する能力を持つ
- 現行の「Refinement-via-Editing（RvE）」：ミスアライン領域への編集指示を生成し、整合部分を保持
- しかしRvEの修正空間は狭く、大規模な変更が必要なケースで性能が頭打ち

## 提案手法：Refinement via Regeneration

- 部分修正ではなく**全体再生成**の空間を活用
- 修正空間を拡大することで、より根本的な品質改善が可能
- UMMの理解と生成の統合を最大活用した反復的精緻化

## 実験結果

- T2Iベンチマークで既存のRvEアプローチを超える品質改善
- 大きな意味的変更が必要なケースで特に優位

## 意義

統一マルチモーダルモデルの自己精緻化能力を新パラダイムで強化。生成AIの反復改善フローに実践的な設計指針を提供。
