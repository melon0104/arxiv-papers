# YOSE: You Only Select Essential Tokens for Efficient DiT-based Video Object Removal

- **arXiv**: http://arxiv.org/abs/2604.27322v1
- **Published**: 2026-04-30
- **Authors**: Chenyang Wu, Lina Lei, Fan Li, Chun-Le Guo
- **Category**: cs.CV

## 概要

DiT（Diffusion Transformer）ベースのビデオ生成技術は映像オブジェクト除去で優れた品質を示しているが、推論遅延が大きな課題。例えばMiniMax Removerは最高水準の画質を実現するが、時空間トークン空間全体への密な計算により約10FPSしか出ない（マスク領域のみを処理すべきにもかかわらず）。

**YOSE（You Only Select Essential tokens）** はこの問題を解決する効率的DiT推論フレームワーク。

## 主な貢献

- **エッセンシャルトークン選択**: 実際に処理が必要なトークン（マスク領域周辺）のみに計算を集中
- DiTベースのビデオ拡散モデル全般に適用可能な汎用的アプローチ
- MiniMax Remover水準の画質を維持しながら大幅な推論高速化を実現

## 意義

ビデオ生成・編集の実用化の壁であるリアルタイム処理を目指す研究。DiTモデルの計算効率化に対する実践的アプローチ。
