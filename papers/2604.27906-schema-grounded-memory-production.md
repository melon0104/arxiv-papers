# From Unstructured Recall to Schema-Grounded Memory: Reliable AI Memory via Iterative, Schema-Aware Extraction

- **arXiv**: http://arxiv.org/abs/2604.27906v1
- **Published**: 2026-04-30
- **Authors**: Alex Petrov, Alexander Gusak, Denis Mukha, Dima Korolev
- **Category**: cs.CL
- **Keyword match**: production（本番環境での要件を直接扱う）

## 概要

永続的AIメモリを「検索問題」として扱う既存設計の根本的な不一致を指摘。テキストを保存・埋め込んで後で取得する方式はテーマ的な想起には有用だが、**エージェントが本番環境で必要とするメモリの種類（正確な事実、現在の状態、更新・削除、集約、関係、否定クエリ、明示的な未知）に対してミスマッチ**。

## 主な提案

- **スキーマグラウンデッドメモリ**: 検索システムではなく「レコードシステム」としてメモリを設計
- **反復的・スキーマ認識型抽出**: 会話から構造化スキーマへのイテラティブな情報抽出パイプライン
- 本番AIエージェントの実際のメモリ要件（状態管理・事実更新・否定クエリ）をカバー

## 意義

AIエージェントのメモリアーキテクチャ設計に対する重要な視点転換。RAGだけでは不十分な理由を明確化し、構造化メモリの必要性を論じる。
