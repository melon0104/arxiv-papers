# Agent-Agnostic Evaluation of SQL Accuracy in Production Text-to-SQL Systems

- **arXiv**: http://arxiv.org/abs/2604.28049v1
- **Published**: 2026-04-30
- **Authors**: Taslim Jamal Arif, Kuldeep Singh
- **Category**: cs.AI
- **Keyword match**: production（本番T2SQLシステムの評価問題を直接扱う）

## 概要

**本番環境のText-to-SQL（T2SQL）評価**には既存ベンチマークが対処しない根本的課題がある。現在の評価手法（ルールベースSQLマッチング・スキーマ依存セマンティックパーサー）はグラウンドトゥルースクエリと構造化スキーマへのアクセスを前提とするが、**実際の本番デプロイではこの制約がほぼ満たされない**。このギャップがプロダクションT2SQLエージェントを開発者テスト以降ほぼ未評価のまま放置し、サイレントな品質劣化を招いている。

## 主な貢献

- **エージェント非依存評価**: 特定のエージェントアーキテクチャに依存しないSQL精度評価手法
- スキーマアクセスやグラウンドトゥルースなしでの本番評価フレームワーク
- 実運用T2SQLシステムの継続的品質監視を可能にする

## 意義

Text-to-SQLの本番運用において見落とされがちな評価ギャップを解決。実際にT2SQLを社内デプロイしているチームに直接役立つ実践的研究。
