# Auto-FlexSwitch: Efficient Dynamic Model Merging via Learnable Task Vector Compression

- **arXiv**: http://arxiv.org/abs/2604.28109v1
- **Published**: 2026-04-30
- **Authors**: Junqi Gao, Dazhi Zhang, Zhichang Guo, Biqing Qi
- **Category**: cs.LG

## 概要

モデルマージは複数のタスク特化モデルから知識を統合するマルチタスク適応の有効なアプローチ。動的マージはタスク間のパラメータ競合による性能低下を緩和できるが、**各タスクの独立パラメータを保存するため膨大なストレージが必要**になる問題があった。

**Auto-FlexSwitch** は学習可能なタスクベクトル圧縮でこのストレージボトルネックを解決。

## 主な貢献

- **学習可能なタスクベクトル圧縮**: ストレージを大幅削減しながら動的マージ性能を維持
- 推論時に柔軟にタスク特化パラメータを組み合わせる効率的スイッチング
- 圧縮によって性能劣化を最小限に抑える最適化設計

## 意義

モデルマージ・タスク特化適応の実用化障壁であったストレージ問題を解決。複数タスクを単一モデルで効率的に処理したいエンタープライズ応用に有用。
