# Auto-FlexSwitch: Efficient Dynamic Model Merging via Learnable Task Vector Compression

**ArXiv**: https://arxiv.org/abs/2604.28109  
**Published**: 2026-04-30  
**Category**: cs.LG  
**Authors**: Junqi Gao, Dazhi Zhang, Zhichang Guo

## 一言サマリー
学習可能なタスクベクトル圧縮により動的モデルマージのストレージオーバーヘッドを大幅削減しながら高性能を維持するAuto-FlexSwitch

## 選定理由
- モデルマージという2025-2026年の重要トレンドへの貢献
- 推論時の動的適応に必要なストレージ問題を解決

## 概要
モデルマージは複数タスク特化モデルの知識を統合する効果的な多タスク適応手法。動的マージは推論時にタスク固有パラメータを柔軟に組み合わせて高性能を維持するが、タスクごとに独立したパラメータを保存するため膨大なストレージが必要。Auto-FlexSwitchは学習可能なタスクベクトル圧縮でこの問題を解決。

## 主な貢献
- 学習可能なタスクベクトル圧縮による高効率動的モデルマージ
- 大幅なストレージ削減（複数タスク対応に必要な独立パラメータを圧縮）
- パラメータコンフリクトを動的に回避しながら推論品質を維持
- 推論時の軽量な動的切替を可能にするアーキテクチャ設計
