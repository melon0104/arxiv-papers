# Synthetic Computers at Scale for Long-Horizon Productivity Simulation

**ArXiv**: https://arxiv.org/abs/2604.28181  
**Published**: 2026-04-30  
**Category**: cs.CL  
**Authors**: Tao Ge, Baolin Peng, Hao Cheng (Microsoft Research)

## 一言サマリー
リアルなディレクトリ構造・文書アーティファクトを持つ合成PC環境を大規模生成し、長期的生産性タスクのシミュレーション用合成データ基盤を構築（Microsoft）

## 選定理由
- Microsoft Research著者
- GUI Agentの長期水平タスク研究という重要テーマ
- 合成データスケーリングのインフラ研究

## 概要
長期的な生産性作業（productivity work）はユーザー固有のPC環境（ディレクトリ・文書・スプレッドシート等）に強く依存する。この種のタスク用合成データを大規模に生成するため、「Synthetic Computers at Scale」を提案。リアルなフォルダ階層とコンテンツ豊富なアーティファクトを持つ合成PC環境を自動生成する手法。

## 主な貢献
- 現実的なPC環境（ディレクトリ構造＋文書類）の大規模自動生成手法
- ユーザー固有コンテキストを考慮した合成データ生成パイプライン
- 長期水平タスクのシミュレーション用ベンチマーク基盤
- Microsoft Research製の産業スケール検証済み手法
