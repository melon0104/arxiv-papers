# Representation Fréchet Loss for Visual Generation

**ArXiv**: https://arxiv.org/abs/2604.28190  
**Published**: 2026-04-30  
**Category**: cs.CV  
**Authors**: Jiawei Yang, Zhengyang Geng, Xuan Ju

## 一言サマリー
評価指標としてのみ使われてきたFréchet距離（FD）を表現空間で実際の訓練目標として有効活用できることを示す—FD-lossの提案

## 選定理由
- 長年評価指標に留まっていたFréchet距離を訓練目標に転換するアイデアの新規性
- 視覚生成モデルの品質向上に直結する実用的な貢献

## 概要
Fréchet距離（FD）は視覚生成の評価には広く使われてきたが、実際の訓練目標としては実用的でないと考えられてきた。本論文はこの常識を覆す：FD推定用の母集団サイズ（例：50K）と勾配計算のバッチサイズ（例：1024）を分離することで、FD-lossとして有効に最適化できることを示す。

## 主な貢献
- FD推定サイズとバッチサイズを分離するFD-lossの設計
- 異なる表現空間でFD-lossを最適化すると視覚品質が一貫して向上
- 既存ベースジェネレータのポストトレーニングに適用可能
- 評価指標と訓練目標の統一による生成モデル改善
