# LaST-R1: Reinforcing Action via Adaptive Physical Latent Reasoning for VLA Models

- **arXiv**: http://arxiv.org/abs/2604.28192v1
- **Published**: 2026-04-30
- **Authors**: Hao Chen, Jiaming Liu, Zhonghao Yan, Nuowei Han
- **Category**: cs.RO

## 概要

VLA（Vision-Language-Action）モデルは複雑なロボット操作のために推論メカニズムを取り入れているが、既存アプローチに**共通の根本的制約**がある：明示的な言語推論（遅延と離散化の問題）または連続潜在推論（より表現力が高い）のいずれであれ、**静的な模倣学習に閉じており適応性と汎化を制限**している。

**LaST-R1** はオンラインRLと適応的物理潜在推論を組み合わせてこの制約を打破。

## 主な貢献

- **オンラインRL + 適応的物理潜在推論**: 静的模倣学習の枠を超えた動的適応
- 物理的な操作タスクに特化した潜在推論空間の設計
- 模倣学習と強化学習を統合した訓練パイプライン

## 意義

LLM推論をVLAモデルに統合する研究の最前線。ロボット操作の汎化と適応性向上への重要なアプローチ。先日の2604.28192（前日同号論文）との連続性も注目。
