# Intelligent Elastic Feature Fading: Enabling Model Retrain-Free Feature Efficiency Rollouts at Scale

**Authors:** Jieming Di, Xiaoyu Chen, Ying She, Siyu Wang, Lizzie Liu, Fenggang Wu, Jiaoying Mu, Tony Tsui, Amr Elrouwy, Hsing Tang, Zewei Jiang, Qiao Yang, Lin Qi, Haibo Lin, Weifeng Cui, Daniel Li, Kapil Gupta, Shivendra Pratap Singh, Jie Zheng, Arnold Overwijk, Ling Leng, Sri Reddy, Robert Malkin, Rocky Liu

**arXiv:** https://arxiv.org/abs/2605.00324

## 概要

大規模ランキングシステムは複数の時間軸にわたるユーザー行動から派生した数千のフィーチャに依存している。従来の手法では特徴廃止時にモデル再学習が必要で、3〜6ヶ月のイテレーションサイクル・大量GPU消費・限られたスループットをもたらしていた。

本論文は **Intelligent Elastic Feature Fading (IEFF)** を提案する。これはモデル再学習なしで特徴効率化ロールアウトを可能にするフレームワークで、産業規模での展開を実証している。

## キーポイント

- **モデル再学習不要**: 特徴廃止・段階的フェードアウトをオンラインで実行
- **産業実装**: 大規模プロダクション環境での検証済み
- **弾性設計**: 特徴の重要度を動的に調整、段階的なロールアウトが可能
- **GPU効率化**: 再学習コストを削減しイテレーション速度を向上

## 選定理由

- 大規模な産業チーム（20名以上の著者）
- production・at scaleの実装記載
