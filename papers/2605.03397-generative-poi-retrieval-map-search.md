# Revisiting General Map Search via Generative Point-of-Interest Retrieval

## 概要

POI（地点情報）検索における「不明確なユーザークエリ」問題に取り組んだ論文。一般的なマップ検索では、ユーザーのクエリが文脈依存・パーソナライズされており、表層的なセマンティクスマッチングに過度に依存する従来手法では対応困難。生成的POI検索アプローチで大規模POIデータベースから適切な候補を識別する新手法を提案。

## 主な貢献

- 不完全指定クエリに対するGenerative POI検索フレームワークを提案
- 文脈依存・パーソナライズされたマップ検索に対応
- 大規模POIデータベースでの高精度検索を実現
- 実際のマップサービスシナリオでの有効性を実証

## 重要性

地図・位置情報サービスの検索は日常的に数億人が使用するサービス。生成的アプローチをPOI検索に適用した先進的研究で、実サービスへの応用可能性が高い。
