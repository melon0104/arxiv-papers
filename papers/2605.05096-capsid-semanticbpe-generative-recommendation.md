# CAPSID + SEMANTICBPE: Soft-Routed Variable-Length Semantic IDs for Generative Recommendation

## 概要

生成推薦（Generative Recommendation）の核心ボトルネックである「トークナイザー」を改良した研究。従来の残差ベクトル量子化（RVQ）はクラスタ境界で多面的なアイテムセマンティクスを潰してしまう問題があった。CAPSIDはカプセルルーティングでソフトな残差量子化を実現し、SEMANTICBPEはBPEアルゴリズムでSIDトークンを再利用可能なサブワードに圧縮する。

## 主な貢献

- **CAPSID**: ハードな1-of-N割り当てをカプセルルーティングに置き換え、アイテムが複数のセマンティックカプセルに確率的にルーティング
- **SEMANTICBPE**: 隣接するSIDトークンの共起と埋め込み互換性を組み合わせてサブワード構築
- Amazon Beauty/Sports/Toys + 35Mアイテムの産業用カタログで評価、Recall@10を平均9.6%改善（最強シングル表現ベースラインReSID比）
- COBRA式のスパース＋デンス複合システムと同等以上の性能を推論レイテンシ51%で達成

## 重要性

産業規模（35M items）での評価と明示的なレイテンシ比較で実用性を示した点が強み。テールアイテムでの改善幅が最大という知見は、ロングテール推薦問題への応用に直結する。
