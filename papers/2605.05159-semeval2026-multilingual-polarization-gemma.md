# PSK at SemEval-2026 Task 9: Multilingual Polarization Detection Using Ensemble Gemma Models

## 概要

SemEval-2026 Task 9（多言語極性検出）の参加システム報告。22言語にわたる二値分類タスクに対してGemma 3（12B・27B）を言語別LoRAファインチューニング＋アンサンブルで2位入賞。

## 主な貢献

- GPT-4o-miniによる3種類の合成データ戦略（直接生成・パラフレーズ・コントラスト対）
- 埋め込みベース重複除去を含む多段階品質フィルタリング
- 言語別閾値チューニングで再訓練なしに2〜4%のF1改善
- 平均Macro-F1 0.811（22言語）、3言語で1位・8言語でトップ3
- XLM-RoBERTa・Qwen3はdev setで高性能もtest setで30〜50%F1低下（過学習）

## 重要性

多言語偏極検出という社会的に重要なタスクで、LoRA+合成データ+アンサンブルの実用的組み合わせを検証。一般化性の課題（dev-test乖離）についての知見も有益。
