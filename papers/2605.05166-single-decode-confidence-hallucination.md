# The First Token Knows: Single-Decode Confidence for Hallucination Detection

## 概要

LLMのハルシネーション検出において、複数サンプリングによるセマンティック自己一貫性（semantic self-consistency）と同等以上の性能を、単一グリーディデコードの**最初のトークン**のエントロピーで達成できることを示した研究。

## 主な貢献

- **φ_first**（first-token confidence）: 単一デコードで最初のコンテンツトークンのTop-K logitsの正規化エントロピー
- 3つの7-8B命令チューニングモデル × 2ベンチマークで平均AUROC 0.820を達成（セマンティック一貫性0.793、通常自己一貫性0.791を上回る）
- セマンティック一貫性との相関が中〜強度あり、両者の組み合わせはφ_firstのみとほぼ同等
- マルチサンプル不確実性推定の前に報告すべき低コストベースラインとして推奨

## 重要性

推論コストを大幅削減しながら同等のハルシネーション検出を実現。LLM実運用のコスト効率化に直結する実践的知見。
