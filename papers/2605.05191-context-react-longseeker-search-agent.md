# Context-ReAct & LongSeeker: Elastic Context Orchestration for Long-Horizon Search Agents

## 概要

長期間推論エージェントにおけるコンテキスト管理の新しいパラダイム**Context-ReAct**を提案。5つのアトミック操作（Skip・Compress・Rollback・Snippet・Delete）でエージェントが作業コンテキストを動的に再構成できる。これをベースにしたエージェント**LongSeeker**を構築。

## 主な貢献

- **Context-ReAct**: 推論・コンテキスト管理・ツール使用を統合したエラスティックコンテキスト管理パラダイム
- Compress操作の表現完全性を理論的に証明
- **LongSeeker**: Qwen3-30B-A3Bを10k合成トラジェクトリでファインチューニング
- BrowseComp 61.5%・BrowseComp-ZH 62.5%（Tongyi DeepResearch 43.2%/46.7%を大幅上回る）

## 重要性

長期間ウェブ検索エージェントの実用的ボトルネック「コンテキスト肥大化」を解決する汎用パラダイム。BrowseCompという難ベンチマークで産業システムを上回る性能を達成。
