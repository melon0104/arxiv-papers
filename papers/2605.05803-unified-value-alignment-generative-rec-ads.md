# Unified Value Alignment for Generative Recommendation in Industrial Advertising

**著者**: Xinxun Zhang, Yuling Xiong, Jiale Zhou  
**arXiv**: http://arxiv.org/abs/2605.05803v1  
**投稿日**: 2026-05-07

## 概要

生成推薦（GR）を産業規模の広告システムに適用する研究。GRは次トークン生成として推薦を再定式化する手法で有望だが、産業広告への拡張は非自明。広告システムではユーザー興味だけでなく**商業的価値**（クリック率・コンバージョン率・収益）も同時最適化する必要があるためだ。

本研究では、ユーザー嗜好と広告商業価値を**統一的に整合**させるGRフレームワークを提案。産業広告環境でのリアルな評価実験により、既存GRベースラインを上回る性能を実証。

## 重要ポイント

- 産業広告向けGRの多目的最適化（ユーザー興味 + 商業価値）
- 実産業環境（industrial advertising）での有効性を検証
- GRの実用化研究として注目
