# When to Trust Imagination: Adaptive Action Execution for World Action Models

**Authors:** Rui Wang, Yue Zhang, Jiehong Lin, Kuncheng Luo, Jianan Wang, Zhongrui Wang et al.

**arXiv:** https://arxiv.org/abs/2605.06222

## 概要

World Action Models（WAMs）はロボットマニピュレーションのための有望なパラダイムとして登場し、将来の視覚観測と将来のアクションを共同予測する。しかし現在のWAMは各モデル推論後に固定数のアクションを実行し、ロボットが予測の不確実性に対して盲目になっている。

本論文は「いつ世界モデルの想像を信頼すべきか」という問いに答え、適応的なアクション実行戦略を提案する。

## キーポイント

- **不確実性適応**: 予測の信頼度に基づいてアクション実行を適応的に制御
- **動的実行長**: 固定アクション数から予測品質に応じた動的実行へ
- **安全性向上**: 不確実な予測での過剰実行リスクを回避
- **World Action Model改善**: WAMの実用性を高める重要な補完機能

## 選定理由

- World Action Models（ロボット学習の最新パラダイム）への貢献
- 実装上の重要課題（信頼度推定）への解決策
- ロボットマニピュレーションの実用化に直結

## 一言サマリー

World Action Modelが「いつ自分の想像を信頼すべきか」を学習—予測不確実性に適応したアクション実行でWAMの実用安全性を向上
