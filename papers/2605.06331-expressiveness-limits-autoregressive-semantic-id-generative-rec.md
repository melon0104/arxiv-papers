# Expressiveness Limits of Autoregressive Semantic ID Generation in Generative Recommendation

**著者**: Yupeng Hou, Haven Kim, Clark Mingxuan Ju  
**arXiv**: http://arxiv.org/abs/2605.06331v1  
**公開日**: 2026-05-07  
**分野**: cs.IR（GitHub公開）

## 概要

生成推薦（GR）モデルは離散トークンシーケンスを自己回帰的に生成してアイテムをインデックスするが、このデコーディング空間の構造的な影響はほとんど研究されていない。本研究では、GRモデルが生成するアイテム確率が**デコーディングツリー構造と強く相関**していることを観察する。

セマンティックIDが誘導するデコーディングツリーの葉ノードがアイテムに対応し、モデルの表現能力に根本的な制限を生じさせる。この「表現力の限界」を理論的・実験的に明らかにし、生成推薦の設計に重要な示唆を与える。

## 重要性

生成推薦の理論的限界を初めて体系的に分析した研究。Semantic IDベースの推薦モデル（TIGER、LC-Rec等）の設計者必読の理論的基盤を提供。
