# Expressiveness Limits of Autoregressive Semantic ID Generation in Generative Recommendation

**著者**: Yupeng Hou, Haven Kim, Clark Mingxuan Ju  
**arXiv**: http://arxiv.org/abs/2605.06331v1  
**投稿日**: 2026-05-07

## 概要

生成推薦（Generative Recommendation; GR）モデルは、ターゲットアイテムをインデックスする離散トークン列を自己回帰的に生成することでアイテムを推薦する。しかし、この自己回帰生成プロセスは**構造化デコーディング空間**を誘導し、モデルの表現力への影響がこれまで未検討だった。

本論文では理論・実験の両面から、自己回帰型セマンティックID生成が持つ**表現力の限界**を明らかにする。特に、デコーディング空間の構造がどのようにモデルが推薦できるアイテム分布を制約するかを分析。

## 重要ポイント

- 自己回帰セマンティックIDのデコード空間が推薦の表現力を制約することを理論的に示す
- GRモデルの設計上の盲点を明確化
- 生成推薦の次世代設計への示唆を提供

## 関連技術
