# OA-WAM: Object-Addressable World Action Model for Robust Robot Manipulation

**著者**: Yushan Liu, Peibo Sun, Shoujie Li  
**arXiv**: http://arxiv.org/abs/2605.06481v1  
**投稿日**: 2026-05-07

## 概要

World Action Model（WAM）はシーン変化とロボット行動を同時予測することでVision-Language-Actionポリシーを強化するが、既存手法は予測された世界をホリスティックな画像・ビデオトークン・グローバル潜在表現として表現する。これらの表現はアクションデコーダがオブジェクト固有の情報を参照することを困難にする。

**OA-WAM（Object-Addressable WAM）**はオブジェクトをアドレス可能な単位として扱い、アクションデコーダがオブジェクトレベルの詳細情報に直接アクセスできる設計。これにより、ロバストなロボット操作を実現する。

## 重要ポイント

- オブジェクトレベルの世界表現によるWAMの改善
- アクションデコーダがオブジェクト固有情報を参照可能
- ロボット操作タスクでの性能向上を実証
