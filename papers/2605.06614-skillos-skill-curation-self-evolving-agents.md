# SkillOS: Learning Skill Curation for Self-Evolving Agents

**著者**: Siru Ouyang, Jun Yan, Yanfei Chen  
**arXiv**: http://arxiv.org/abs/2605.06614v1  
**投稿日**: 2026-05-07

## 概要

LLMベースのエージェントはストリーミングタスク処理に広くデプロイされているが、多くは過去のインタラクションから学習できない「一回限り」のソルバーにとどまる。経験から抽出された**再利用可能なスキル**は自己進化の自然な基盤となるが、高品質なスキルキュレーションが鍵となる。

本研究では**SkillOS**を提案：エージェントが継続的にスキルを蓄積・精製・活用することで自己進化できるフレームワーク。スキルキュレーション品質を学習することが、長期的なエージェント性能向上の核心であることを示す。

## 重要ポイント

- 実際にデプロイされたエージェントシステムからの知見
- 継続学習・スキル蓄積による自己進化エージェントの設計
- スキルキュレーションの質がエージェント性能を左右することを実証
