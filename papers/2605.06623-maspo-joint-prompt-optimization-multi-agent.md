# MASPO: Joint Prompt Optimization for LLM-based Multi-Agent Systems

**著者**: Zhexuan Wang, Xuebo Liu, Li Wang  
**arXiv**: http://arxiv.org/abs/2605.06623v1  
**投稿日**: 2026-05-07

## 概要

LLMベースのマルチエージェントシステム（MAS）は複雑な協調タスクに有望だが、エージェントはロール固有のプロンプトで制御される。プロンプト品質が重要なのにもかかわらず、**複数の相互作用するエージェント間でプロンプトを同時最適化**することは非自明な問題だった。

**MASPO（Multi-Agent System Prompt Optimization）**は、MAS内の全エージェントのプロンプトを共同最適化する手法。エージェント間の依存関係を考慮しながら、システム全体の性能を最大化するプロンプトセットを自動探索する。

## 重要ポイント

- マルチエージェントシステムの全エージェントプロンプトを同時最適化
- エージェント間依存関係のモデル化
- 単一エージェント最適化より大幅に優れたシステム性能を達成

## 関連技術

Multi-Agent Systems, Prompt Optimization, LLM, Automatic Prompt Engineering
