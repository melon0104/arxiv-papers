# Recursive Agent Optimization

**著者**: Apurva Gandhi, Satyaki Chakraborty, Xiangjun Wang  
**arXiv**: http://arxiv.org/abs/2605.06639v1  
**投稿日**: 2026-05-07

## 概要

**RAO（Recursive Agent Optimization）**を紹介：再帰的エージェント（自分自身の新しいインスタンスにサブタスクを再帰的に委任できるエージェント）を学習する強化学習アプローチ。

再帰的エージェントは推論時スケーリングアルゴリズムを実装し、エージェントが仕事を並列化・分解できるため、長期複雑タスクに自然に対応。RLの枠組みで再帰的委任を学習させることで、タスク分解と並列化を自動獲得する。

## 重要ポイント

- エージェントが自分自身を再帰的に呼び出す新しいアーキテクチャ
- 推論時スケーリング（inference-time scaling）の自然な実装
- タスク分解・並列化を強化学習で自動習得

## 関連技術

Agentic AI, Reinforcement Learning, Recursive Agents, Inference-Time Scaling
