# Adaptive Domain Decomposition PINNs for Traffic State Estimation with Sparse Sensor Data (ADD-PINN)

**著者**: Eunhan Ka, Ludovic Leclercq, Satish V. Ukkusuri  
**arXiv**: http://arxiv.org/abs/2605.08028v1  
**公開日**: 2026-05-08  
**分野**: cs.LG

## 概要

スパースな固定センサーからの交通状態推定は、PINNがLWR（Lighthill-Whitham-Richards）モデルが許容するショックウェーブを過剰に平滑化する傾向があり困難。

本研究は**ADD-PINN**（Adaptive Domain Decomposition PINN）を提案。2段階の残差誘導フレームワーク：
1. 粗い大域PINNを学習
2. その空間残差プロファイルを使ってサブドメイン境界を配置し、データ駆動ショック指示器付きで子サブネットワークを初期化

オフラインの速度場再構成において、交通ショックウェーブを精度良く捉えることに成功。

## 重要性

物理情報ニューラルネットワーク（PINN）の交通工学への応用。スマートシティ・自動運転インフラにおける交通状態モニタリングの精度向上に直結する実用的研究。
