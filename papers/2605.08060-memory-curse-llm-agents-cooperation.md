# The Memory Curse: How Expanded Recall Erodes Cooperative Intent in LLM Agents

**著者**: Jiayuan Liu, Tianqin Li, Shiyi Du  
**arXiv**: http://arxiv.org/abs/2605.08060v1  
**公開日**: 2026-05-08  
**分野**: cs.CL / cs.AI

## 概要

コンテキストウィンドウの拡大はLLMの単純な能力向上と思われがちだが、マルチエージェントの社会的ジレンマ状況では**系統的に失敗**することを発見した。7種のLLMと4ゲームで500ラウンドにわたる実験で、アクセス可能な履歴を拡大すると28設定中18設定で協力が低下する現象を **"memory curse"** と命名。

分析の結果、この崩壊は妄想的思考の高まりではなく、**前向きな意図の侵食**と関連していることが語彙分析（37.8万件の推論トレース）で明らかになった。LoRAファインチューニングによる認知的プローブ実験でもこれを検証。

## 重要性

長コンテキストLLMエージェントの社会的行動に関する重要な警告。エージェント協調システム設計において、単純な「記憶容量増加＝良い」という前提を覆す反直感的な発見。
